## 🌟 Fitur & Komponen Interaktif (Apple Style)

1.  **Frosted Glass Navbar:**
   - Navigasi transparan bergaya Apple.com (`backdrop-filter: blur(20px)`), menu link bersih, tombol **1-Click Copy Email** dengan animasi Apple Toast notification.

2. 🛞 **Live Interactive 2D Seat Picker (Web PO Bus ASM Putra Trans):**
   - Mini-demo denah kursi bus 2D yang **bisa diklik langsung** di kartu proyek (simulasi pemilihan kursi realtime dan penguncian status *double-booking prevention*).

3. 📱 **Smartphone Frame Mockup (Smart Tourism Kebumen):**
   - Tampilan perangkat mobile native Android dengan notch dan card wisata interaktif.

4. 📡 **ESP32 Live Serial Monitor (Hardware Telemetry):**
   - Terminal monitor bergaya macOS dengan stream telemetry berkala dari mikrokontroler ESP32.

5. 📋 **Apple Tech Specs:**
   - Lembar spesifikasi teknologi (Backend & Logic, Android Kotlin, Database MySQL, Hardware IoT).

6. 💬 **Apple Support-Style Contact Card:**
   - Kartu kolaborasi elegan dengan tombol langsung ke WhatsApp Direct, Email, GitHub, dan formulir pengiriman pesan.
