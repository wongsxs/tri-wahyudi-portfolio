## 🌟 Fitur Unggulan & Komponen Interaktif

1. 🧲 **Magnetic Custom Cursor & Particle Network Canvas:**
   - Kursor kustom fluida dengan cincin *trailing spring physics* dan canvas jaring partikel 60 FPS reaktif kursor.

2. 🔊 **Web Audio Synthesizer (Haptic Audio Feedback):**
   - Sintesis audio frekuensi instan via browser Web Audio API saat berinteraksi dengan elemen UI, lengkap dengan tombol kontrol toggle Audio ON/OFF di navbar.

3. 💻 **Interactive Developer Terminal Shell (`wongsxs@dev:~$`):**
   - Konsol terminal CLI fungsional di halaman hero. Mendukung perintah `help`, `about`, `projects`, `skills`, `contact`, `date`, `whoami`, serta Easter Egg `matrix` (Cyber Digital Rain).

4. 🧊 **3D Gyroscope Card Tilt Physics:**
   - Efek kemiringan perspektif 3D dinamis (`rotateX/rotateY`) pada setiap kartu Bento Grid dan modul statistik.

5. 🚎 **PO Bus ASM Putra Trans — Live Seat Reservation & E-Ticket Boarding Pass:**
   - Denah kursi eksekutif 2+2 dinamis, kalkulator tarif tiket instan, dan generator tiket *Boarding Pass* fisik lengkap dengan barcode dan QR validasi.

6. 📱 **Smart Tourism Kebumen — Interactive Android Device:**
   - Mockup smartphone Android dengan jam *live* dan navigasi destinasi wisata yang mengganti rute, jarak, dan koordinat secara *real-time*.

7. ⚡ **ESP32 Firmware Telemetry & GPIO Switchboard:**
   - Konsol serial UART 115200 baud dengan saklar fisik interaktif (Relay 1, Relay 2, LED Built-in) yang memicu log interupsi perangkat keras.

8. 💼 **Company DAU B2B Catalog & WhatsApp RFQ Generator:**
   - Selector peralatan industri dengan kuantitas unit dinamis yang otomatis merangkai tautan pesan penawaran WhatsApp resmi.

9. 🟩 **Simulated 52-Week GitHub Heatmap:**
   - Visualisasi grid aktivitas commit 365 hari ala profil GitHub asli dengan level intensitas warna hijau dan *commit tooltip*.

10. ⌨️ **Quick Search Command Palette (`Ctrl + K` / `Cmd + K`):**
    - Navigasi cepat ala Raycast / Spotlight untuk melompat antar section dan menyalin email seketika.
