## 📁 Daftar Project & Analisis Sistem

Berikut adalah proyek unggulan yang telah dikembangkan dan dianalisis arsitekturnya:

1. 🚌 **Web PO Bus (ASM Putra Trans / `asmputratrans`)**
   - *Analisis Sistem:* Solusi pemesanan tiket bus antarkota, denah pemilihan kursi 2D interaktif (seat matrix), penjadwalan trayek, dan tiket digital QR Code.
2. ✨ **Web Perusahaan Alat Kebersihan (`companyDAU`)**
   - *Analisis Sistem:* Portal korporat dan e-katalog B2B perlengkapan kebersihan komersil (mesin polisher, chemical, scrubber), sistem kalkulasi RFQ otomatis, dan integrasi WhatsApp sales.
3. 📱 **Smart Tourism Kebumen (`smart-tourism-kebumen-v1` / `WisataKebumen3.0`)**
   - *Analisis Sistem:* Aplikasi native Android berbasis Kotlin untuk direktori destinasi wisata, navigasi geolocation peta, dan informasi rute wisata Kebumen.
4. 📋 **Sistem Web Absensi GAMKI (`absensi-gamki`)**
   - *Analisis Sistem:* Aplikasi web presensi kehadiran delegasi kegiatan organisasi, pencatatan realtime, dan rekapitulasi data otomatis.
5. ☁️ **KT Cloud Storage (`kt-cloud`)**
   - *Analisis Sistem:* Sistem cloud storage personal berbasis TypeScript yang terintegrasi dengan Google Drive API via OAuth2.
6. 🤖 **ESP32 IoT Controller (`ESP32project`)**
   - *Analisis Sistem:* Firmware C++ mikrokontroler ESP32 untuk otomasi perangkat keras, pembacaan sensor, dan telemetri Wi-Fi.
7. 🎣 **Mancing Game Web Engine (`mancing-game`)**
   - *Analisis Sistem:* Game 2D berbasis HTML5 Canvas dengan simulasi fisika memancing dan sistem skor.
