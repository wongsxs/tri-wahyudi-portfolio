STAGE 01 INTEL & ANALISIS

WEB PO BUS (ASM PUTRA TRANS / RESERVASI BUS)

Analisis Masalah: Perusahaan otobus antarkota membutuhkan sistem digital untuk mengeliminasi resiko tiket ganda (double-booking), memantau ketersediaan kursi secara visual, serta mencatat manifest penumpang dan jadwal armada secara terpusat.

ARSITEKTUR & FITUR UTAMA:

  • 2D Interactive Seat Matrix: Menggunakan struktur array 2 dimensi untuk memetakan denah kursi bus (eksekutif 2-2, sleeper, dsb.) dengan status real-time.
  • Manajemen Rute & Jadwal: Relasi database antara terminal asal, terminal tujuan, waktu tempuh, dan penyesuaian tarif dinamis.
  • Validasi Tiket QR Code: Meng-generate QR Code unik pada setiap e-ticket untuk verifikasi cepat oleh kondektur bus di lapangan.
  • GitHub Repository: Tersedia di wongsxs/asmputratrans.
